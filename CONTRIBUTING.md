# Contributing

Thanks for your interest in improving this project.

## Development setup

```bash
git clone https://github.com/nadirzhon/jsintel
cd jsintel
pip install -r requirements.txt
```

## Before submitting a PR

- Run the linter: `flake8 . --max-line-length=120`
- Run tests if present: `pytest`
- Keep commits focused and write clear messages (`feat:`, `fix:`, `docs:`, `test:`, `chore:`)

## Reporting bugs

Open an issue using the Bug Report template. Include the command you ran, your environment, and the full error output.

## Responsible use

This is a security tool. Contributions must not add functionality whose primary purpose is to attack systems without authorization. Keep it useful for defenders and authorized testers.
